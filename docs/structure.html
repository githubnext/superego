µ mu: structure

An Electron agent environment with a small core: one daemon per machine, its own protocol, thin clients. As of c88a748, 7 commits.

1 · Processes

Agents live in the daemon. Apps and the CLI are clients. Quitting the app never stops an agent.

2 · Packages

Arrows point at dependencies. protocol is the contract; everything else builds on it.

3 · Protocol

JSON-RPC 2.0, one message per line, any transport. hello checks the generation and announces features and the machine's identity and build. Watches send a snapshot, then deltas.

app/Electron profile; single-instance lock

Rule (from T3 Code): client preferences stay in the client; machine defaults stay on the machine. "All machines" is a bulk edit, not a global default.
